# Standalone Activities

**Introduced:** Go SDK support GA September 2026.

Open `/scenario/standalone`.

## What was harder

One-off jobs were often wrapped in a workflow, a scheduler, or an application-owned queue.

## What is simpler

The client starts an Activity directly on a task queue and obtains an activity handle for lifecycle operations and results.

## Run

Press **Submit standalone activity** while the Temporal worker is running.
