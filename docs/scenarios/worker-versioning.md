# Worker Versioning

**Promoted to public preview:** 2025.

Open `/scenario/worker-versioning`.

## What was harder

Deploying workflow code safely needed manual task queues, continue-as-new bridges, or a separate compatibility layer.

## What is simpler

Deployment-aware routing and pinning let workflows run on known worker versions while compatible code is rolled out.

Status can change during 2025–2026; check the pinned SDK/server release before an audience demo.
